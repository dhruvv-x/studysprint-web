StudySprint website + web app
=============================

Files
  index.html       Landing page (open this first)
  app/index.html   The working StudySprint web app

Run on your computer
  Just double-click index.html. No install, no server, no internet needed.
  (The app saves data in your browser, so it works from a file too.)

Put it online (free options)
  - Netlify: drag and drop this whole folder at app.netlify.com/drop
  - GitHub Pages: push the folder to a repo, enable Pages
  - Vercel / Cloudflare Pages: upload the folder, no build command needed

Things to edit
  - index.html: search for "hello@example.com" and put your real email.
  - index.html: footer says "Made by Pookie", change it if you like.
  - Your data stays only in that browser (localStorage), not on a server.
