Features

Subjects and tasks

Group tasks under subjects and set a priority of low, medium or high.

Session planner

Pick tasks, set minutes for each and choose whether to add breaks between them.

Reliable timer

The timer works from saved timestamps, so the time stays correct even if Android closes the app.

History and daily goal

See past sessions, your study time over 7 or 30 days, and progress toward your daily goal.

How it works

Add subjects

Create a subject for each course you study.

Add tasks

Add tasks under a subject and set a priority.

Plan a session

Select tasks, set minutes for each and choose breaks.

Start the timer

Each block runs in order. Review the session when it ends.

FAQ

Does it need internet?

No. The app works offline and does not make network calls.

Which Android versions are supported?

Android 7.0 (API 24) and newer.

Is it free?

Yes. StudySprint is a personal project and is free to use.
